# RAZ Study Reader · 小小精读

**简体中文** | [English](README.en.md)

小小精读是一款面向孩子和家长的英语精读工具。孩子可以先看书、自己读；遇到不懂的句子，点一下查看中文讲解，或点击喇叭听对应音频。读完后，通过小练习巩固表达，再用错题练习和隔天复习回顾。

支持 Android 手机、平板和电脑网页。学习记录保存在本机，无需注册账号，无广告。

> 安装包不附带 RAZ 教材。开始阅读前，需要自行准备有权使用、适配本软件的 `.razpack` 资源包。讲解、音频和练习是否齐全，取决于所导入资源包的内容。

## 开始使用

当前版本为 **1.0.0**，正在正式发布前整理，尚未提供公开安装包下载或在线体验地址。

### 1. 安装或打开阅读器

- **Android 手机 / 平板：**取得 APK 后，在设备上打开安装。最低要求 Android 7.0，具体设备兼容性仍需实测。
- **电脑网页：**打开部署好的阅读器网址，使用新版 Chrome 或 Edge。当前可自行运行网页，方法见 [开发与构建](docs/development.md)。

### 2. 导入自己的资源包

在书架点击 **管理资源包 → 导入资源包**，选择对应级别的 `.razpack` 文件，等待校验完成即可。无需解压；普通 PDF、MP3 不能直接作为资源包导入。

可以只导入当前正在读的级别。以后换级别时，再导入其他包；同一级别有更新时，重新导入新包即可。详细操作见 [资源包说明](docs/resource-packs.md)。

### 3. 看书、听句子、做练习

1. 在书架选一本书，进入阅读页面，点击底部页码可选页跳转。
2. 点击书页上有讲解的句子，查看翻译和讲解；有对应音频时，讲解中会显示喇叭按钮。
3. 打开页码菜单中的 **读后练习**，按原文完成句子还原。不会时可以看讲解，作答后也能回看书中讲解。
4. 回到书架，使用 **错题练习** 和 **隔天复习** 回顾已学表达；需要练习或复习时会显示相应内容。

### 4. 保存学习记录

阅读位置会自动保存在本机。在书架打开 **阅读设置**，可 **导出学习记录**；换设备时，在新设备导入相同资源包，再 **导入学习记录**。

学习记录备份不包含书籍。请分别保留资源包和记录文件；卸载应用、清除应用或网站数据都会清除本机保存的内容和记录。

## 常见问题

**为什么第一次打开没有书？**

阅读器与教材分开提供，初始是空书架。本仓库不提供 RAZ 教材或资源包下载，请自行准备有权使用的资源。

**可以离线使用吗？**

Android 导入资源包后可以离线阅读、播放包内音频和练习。网页需先完成程序的离线缓存准备，再在同一浏览器、同一网址下使用；资源包管理页可以查看离线准备状态。

**手机、平板和电脑会自动同步吗？**

目前不会自动同步。各设备分别保存资源和进度，可以通过导出、导入学习记录迁移。网页换浏览器或换网址，也不会自动带走原来的数据。

**孩子的数据会上传吗？**

阅读器不要求账号，不自动上传阅读和作答记录。网页首次访问需加载程序文件，具体数据说明见 [隐私说明](docs/privacy.md)。
