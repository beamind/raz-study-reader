# 隐私说明

适用版本：RAZ 小小精读 1.0.0。日期：2026-10-29。

阅读器不要求注册账号，不接入广告、用户行为统计、云端学习记录或联网 AI 服务。程序读取用户自行选择导入的资源包，阅读位置、字号、练习答案、错题与复习安排保存在当前设备。

Android 通过系统文件选择器读取所选资源包和记录备份，导出时由用户选择保存位置，不申请整盘文件访问权限。已导入的资源保存在应用私有目录，学习记录保存在本地应用存储；已关闭 Android 系统自动备份。卸载应用或清除应用数据会移除这些数据。

浏览器将资源保存在当前网站的 OPFS 中，学习记录保存在当前浏览器的网站存储中。切换浏览器、地址或端口不会自动迁移数据；清除网站数据会删除本机资源和记录。首次访问网站时需要从用户选择的服务器加载程序文件，服务器可能按自身配置记录常规访问日志；阅读器本身不设置分析或跟踪服务。

学习记录导出文件包含阅读和练习进度，资源包包含书籍内容。导出或分享这些文件由用户主动发起；应用不会自动上传它们。请家长自行保管备份，不公开包含孩子学习记录的文件。

Android 声明网络权限供 WebView/Capacitor 本地服务使用；当前应用未配置远程程序地址或在线更新服务。下载 APK、打开外部网站或将导出文件保存到第三方云盘时，还应查看对应服务的隐私规则。

如报告问题，请在项目 Issue 中描述版本和复现步骤，不附孩子个人信息、私钥、签名密码或完整学习记录。
